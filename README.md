# Birthday page for Modassera Nehal

React + Vite + Tailwind. No backend needed.

- Edit text and dates: `src/config.js`
- Add your song: put it at `public/song.mp3` (player hides itself if the file is missing)
- Preview: `npm run dev`
- Deploy: push to GitHub and import in Vercel (Framework: Vite, build `npm run build`, output `dist`), or run `npx vercel`
